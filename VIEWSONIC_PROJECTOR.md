# ViewSonic Projector for Windows 7 Emulator

Open [`viewsonic-projector/`](viewsonic-projector/) in GitHub Pages or run `./viewsonic_projector.sh` locally. The experience is a Windows 7-style ViewSonic projector control room for casting media to a TV or projector.

## Included

- Photo Booth camera with Normal, Colorful, Rainbow, Invert, Hue, Spectrum, and Bomb Explosion effects.
- Selectable photos and videos from the local device.
- ViewSonic projector, TV, wireless display, and HDMI destinations.
- Remote control buttons: ◀️ ▶️ 🆗 🔼 🔽 🎤 🎙️ 🔊 📷 📸.
- NETFLIX, YOUTUBE, AMAZON PRIME VIDEO, MOVISTAR TV, GUIDE TV, and WEB BROWSER launcher buttons.

- Vue UI (`index.html`), JavaScript behavior (`app.js`), CSS styling (`style.css`), JSON settings, XML integration manifest, Ruby server, and Shell launcher.

Browser camera, microphone, and screen-casting permissions are requested only after pressing the related control. The app provides a local browser simulation; it does not connect to real ViewSonic hardware without a compatible browser/device transport.
