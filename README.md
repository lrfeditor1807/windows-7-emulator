# Windows 7 Emulator

A browser-based Windows 7-inspired desktop emulator built with plain HTML, CSS, and JavaScript. It includes a glass-style desktop, Start menu search, taskbar-pinned applications, draggable windows, wallpaper personalization, demo Solitaire, Notepad, WordPad, Calculator, File Manager, Chrome, Media Center and Media Player views.

Open `index.html` in a browser or enable GitHub Pages for the repository. No build step is required.

## Keyboard shortcuts

- `Ctrl + P` — Print
- `Ctrl + E` — Open File Manager
- `Ctrl + C` / `Ctrl + V` — Copy / paste using the browser clipboard behavior
- `Ctrl + A` — Open the Start menu / jump list (when not editing text)

External wallpapers and reference links are included in the Personalization and Sound Recorder apps.
